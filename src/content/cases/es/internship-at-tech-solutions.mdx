<Section title="Desarrollo del frontend">

El frontend se desarrolló con Next.js 14, un framework que ofrece renderizado del lado del servidor y generación de sitios estáticos, lo que lo hace ideal para una aplicación web de alto rendimiento. Next.js nos permitió entregar una interfaz rápida y adaptable, algo crucial en la operación de un restaurante, donde las actualizaciones en tiempo real son esenciales.

</Section>

Elegimos Next.js por su capacidad para manejar rutas complejas y renderizado del lado del servidor, y por su integración natural con React. useContext nos permitió manejar el estado entre distintos componentes de forma eficiente, en especial las sesiones de usuario y los datos de los pedidos. Para los estilos integramos TailwindCSS, que dio un diseño consistente y adaptable en toda la aplicación.

</Detail>

<Section title="Desarrollo del backend">

El backend se desarrolló con Express y Node.js, con el foco en crear una API robusta y escalable para gestionar las operaciones del restaurante. La arquitectura se diseñó con el patrón Repository y Prisma como ORM para interactuar con la base de datos SQL. Esta configuración dio una separación clara de responsabilidades y facilitó mantener y extender el código.

</Section>

<Section title="Resultados y beneficios">

La aplicación web mejoró significativamente la operación del restaurante: automatizó la gestión de pedidos, redujo errores y agilizó el servicio. La combinación de un frontend adaptable con un backend sólido ofreció una experiencia fluida tanto al personal como a los clientes, con más eficiencia y mayor satisfacción.

<Section title="Aprendizajes clave">

Este proyecto reforzó la importancia de elegir las tecnologías adecuadas según los requerimientos. Next.js y useContext ofrecieron una forma eficiente de manejar el frontend, mientras que el backend se benefició de la arquitectura modular que permitieron el patrón Repository y Prisma. Además, la experiencia dejó clara la necesidad de pruebas y documentación exhaustivas, que fueron cruciales para el éxito del proyecto.

</Section>
